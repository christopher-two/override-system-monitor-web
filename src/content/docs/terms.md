## 1. Aceptación de los Términos

Al descargar, instalar o utilizar **Override System Monitor** ("la Aplicación"), aceptas estar sujeto a estos Términos de Uso. Si no aceptas estos términos, no debes usar la Aplicación.

## 2. Descripción de la Aplicación

Override System Monitor es una aplicación de monitoreo de sistema para dispositivos Android que proporciona información en tiempo real sobre:

- **Batería**: Nivel, estado de carga, salud y temperatura
- **Memoria RAM**: Uso total, disponible y porcentaje
- **Almacenamiento**: Análisis de almacenamiento interno y externo
- **Sensores**: Acelerómetro, giroscopio, magnetómetro y más
- **Red**: Conectividad WiFi y celular, velocidad de transferencia
- **Dispositivo**: Modelo, versión de Android, uptime del sistema

## 3. Permisos y Datos

La Aplicación requiere los siguientes permisos para funcionar correctamente:

| Permiso | Propósito |
|---------|-----------|
| `INTERNET` / `ACCESS_NETWORK_STATE` | Verificar conectividad de red |
| `ACCESS_WIFI_STATE` | Obtener información de la conexión WiFi |
| `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` | Identificar redes WiFi cercanas |
| `READ_PHONE_STATE` | Obtener información del dispositivo |
| `ACTIVITY_RECOGNITION` | Monitorear sensores de actividad |

> **Nota**: Los datos recopilados se utilizan únicamente para proporcionar las funciones de monitoreo de la aplicación y **no se comparten con terceros**.
